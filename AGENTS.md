# AI Agent Instructions for LearnPlaywright

This repository contains JavaScript learning examples organized into chapter folders.

## What this project is

- A small educational workspace for learning JavaScript and Playwright concepts.
- Files are simple script examples, not a packaged application.
- There is no package.json, test runner, or build configuration in the repository.

## Key conventions

- Source files live under chapter folders such as `Chap_1_BASICS`, `Chap_2_javascript_concepts`, `Chap03`, `Chap04_Literal`.
- Keep changes simple and consistent with the existing style: straightforward JS examples, `console.log`, and minimal abstractions.
- Avoid introducing project scaffolding or tooling unless the user explicitly requests it.

## How to help

- Focus on correcting or improving example code, explaining JavaScript behavior, and adding small demo scripts.
- When asked to create new content, prefer adding files within the existing chapter structure.
- Do not assume a test framework or NPM scripts exist.

## What not to do

- Do not add unrelated build systems, dependency management, or framework-specific scaffolding.
- Do not reorganize the repository drastically without user approval.
- Do not assume Playwright is configured unless the user asks for Playwright-specific setup.
